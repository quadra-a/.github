# quadra-a/.github

Shared GitHub metadata for the `quadra-a` organization.

This repository holds organization-level GitHub content such as the public profile README and any shared templates or workflow assets that should live at the organization boundary instead of inside a product repository.

## Current contents

- [`profile/README.md`](profile/README.md) — the organization profile shown on the GitHub org page

## Intended scope

- Organization profile content
- Shared issue, pull request, discussion, and support templates
- Reusable GitHub automation that applies across repositories
